# CLAUDE.md — конституция проекта

Сервис подготовки **проектов возражений** на иски дольщиков для застройщика
(ответчик, 214-ФЗ). Веб-прототип работает **без Claude Code**; мозг — **Google
Gemini** (доступен из РФ), интерфейс — Streamlit.

## Жёсткие инварианты (нарушать нельзя)

1. **Обезличивание до облака.** Любой текст проходит `tools.anonymizer.anonymize()`
   до отправки в Gemini. Реальные ПДн восстанавливаются только в финальном
   `.docx`, локально (`tools.docx_writer`). В агентов уходят только токены.
2. **Суммы считает только калькулятор** (`tools.penalty_calculator`,
   `tools.date_calculator`). LLM арифметику не делает — это запрещено.
3. **Каждый существенный тезис — с источником** (норма/расчёт). Без источника
   тезис не включается (контролирует Критик).
4. **Ни одно требование из иска не теряется** — на каждое отдельный раздел.
5. **На выходе — ПРОЕКТ** с дисклеймером об обязательной проверке юристом.
6. **OCR-фоллбэк не падает.** Нет текстового слоя и OCR недоступен →
   понятное сообщение пользователю, а не трейсбек.

## Архитектура

`app.py` → `agents/pipeline.py` (супервизор-генератор) → агенты-функции
(`analyst → planner → [вопросы] → researcher → generator → critic`) → `tools/`.

Цикл Генератор↔Критик ограничен 3 кругами. Уточнения у пользователя —
через события `("question", …)` генератора (human-in-the-loop).

## Правила кода

- Python 3.11+, типы и docstring, комментарии по-русски.
- Тяжёлые зависимости (Gemini, pdfplumber, OCR, python-docx, natasha)
  импортируются лениво — модули должны импортироваться даже без них.
- Нормы (`tools/legal_norms.py`) требуют проверки актуальной редакции.
- Тесты детерминированных инструментов держим зелёными: `pytest -q`.
