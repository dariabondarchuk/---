# Генератор возражений на иски дольщиков (веб-прототип)

Веб-приложение для застройщика-ответчика (214-ФЗ): загружаете исковое заявление
и ДДУ — получаете **проект возражения** в формате `.docx`.

Работает **без Claude Code**, мозг — **Google Gemini** (доступен из России).
Интерфейс — Streamlit.

> ⚠️ **Это проект, подготовленный ИИ. Не является юридической консультацией.**
> Результат обязательно должен проверить квалифицированный юрист.

## Что внутри

| Компонент | Файл | Назначение |
|---|---|---|
| Веб-интерфейс | `app.py` | загрузка PDF, ход работы, скачивание .docx |
| Мозг (Gemini) | `agents/llm.py` | обёртка над `langchain-google-genai` |
| Агенты | `agents/{analyst,planner,researcher,generator,critic}.py` | бывшие субагенты как функции |
| Оркестратор | `agents/pipeline.py` | конвейер с уточняющими вопросами и циклом доработки |
| Расчёты | `tools/penalty_calculator.py`, `tools/date_calculator.py` | суммы считает только код, не модель |
| Обезличивание | `tools/anonymizer.py` | ПДн вырезаются ДО отправки в Gemini |
| Чтение PDF / OCR | `tools/ocr.py` | текстовый слой + аккуратный OCR-фоллбэк |
| Сборка документа | `tools/docx_writer.py` | .docx + возврат реальных ПДн локально |
| Нормы | `tools/legal_norms.py` | выдержки ФЗ-214, ст.333 ГК, ПП-326 |

## Принципы безопасности

1. **Обезличивание до облака.** Реальные ФИО/адреса/телефоны заменяются токенами
   *до* любого вызова Gemini. Настоящие данные возвращаются только в финальный
   `.docx`, локально (`tools/docx_writer.py`).
2. **Суммы считает калькулятор**, а не LLM. Модель не имеет права на арифметику.
3. **На выходе — проект** с дисклеймером о проверке юристом.

## Установка

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Для распознавания **сканов** (PDF без текстового слоя) дополнительно нужны
системные пакеты:

```bash
# Debian/Ubuntu
sudo apt-get install tesseract-ocr tesseract-ocr-rus poppler-utils
```

Если их нет — приложение не падает, а просит загрузить PDF с текстовым слоем.

## Ключ Gemini

Получите ключ в [Google AI Studio](https://aistudio.google.com/app/apikey) и
задайте перед запуском:

```bash
export GEMINI_API_KEY="ваш-ключ"        # Windows (PowerShell): $env:GEMINI_API_KEY="..."
# необязательно:
export GEMINI_MODEL="gemini-2.0-flash"  # модель по умолчанию
export GEMINI_TEMPERATURE="0.1"         # зажимается в диапазон 0..0.2
```

## Запуск

```bash
streamlit run app.py
```

Откроется в браузере. Загрузите два PDF (иск и ДДУ), нажмите
**«Сгенерировать возражение»**, при необходимости ответьте на уточняющие
вопросы и скачайте готовый `.docx`.

## Тесты

```bash
pytest -q
```

Покрыты детерминированные инструменты — калькулятор сумм, расчёт дат и
обезличивание ПДн (это фундамент, который не должен «галлюцинировать»).
